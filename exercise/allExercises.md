# Go Exercises: From Basics to Real-World Applications

## [1. Hello, World!](1helloWorld.go)
Write a program that prints "Hello, World!" to the console.

## [2. Simple Calculator](2simpleCalc.go)
Create a program that takes two numbers and an operator (+, -, *, /) and prints the result.

## [3. Odd or Even](3oddOrEven.go)
Write a function that checks if a number is odd or even.

## [4. FizzBuzz](4fizzbuzz.go)
Print numbers from 1 to 100. For multiples of 3 print "Fizz", for multiples of 5 print "Buzz", and for both print "FizzBuzz".

## [5. Reverse a String](5reverseStr.go)
Write a function that reverses a string.

## [6. Palindrome Checker](6palindrome.go)
Check if a given string is a palindrome.

## [7. Find Maximum in Slice](7maxValInSlice.go)
Write a function that finds the maximum value in a slice of integers.

## [8. Map of Word Counts](8wordCount.go)
Count the occurrences of each word in a string and store them in a map.

## [9. Unique Elements](9remDuplicates.go)
Remove duplicate elements from a slice.

## [10. Struct for Person](10struct.go)
Define a `Person` struct with name, age, and email. Create and print a few instances.

## [11. JSON Marshal/Unmarshal](11marshalUnmarshal.go)
Marshal a `Person` struct to JSON and unmarshal it back.

## [12. Read File](12readFile.go)
Read a text file and print its contents.

## [13. Write File](13writeFile.go)
Write a string to a new file.

## [14. Command-Line Arguments](14printCLIArgs.go)
Print all command-line arguments passed to your program.

## [15. Simple HTTP Server](15httpServer.go)
Create an HTTP server that responds with "Welcome to Go!".

## [16. HTTP GET Request](16GetRequest.go)
Make an HTTP GET request to a public API and print the response.

## [17. Goroutine Example](17goRoutines.go)
Run two functions concurrently using goroutines.

## [18. Channel Communication](18channels.go)
Use a channel to send and receive data between goroutines.

## [19. Mutex for Safe Counter](19mutex.go)
Create a counter that can be safely incremented by multiple goroutines using a mutex.

## [20. Timer and Ticker]()
Demonstrate the use of `time.Timer` and `time.Ticker`.

## [21. Error Handling](21errorHandling.go)
Write a function that returns an error if a number is negative.

## [22. Custom Error Type](22customError.go)
Define and use a custom error type.

## [23. Interface for Shape](23interfaces.go)
Create an interface `Shape` with `Area()` and `Perimeter()` methods. Implement for `Circle` and `Rectangle`.

## [24. Sorting a Slice](24sortSlice.go)
Sort a slice of structs by a field (e.g., age).

## [25. Dependency Injection](25dependecyInjection.go)
Write a function that takes an interface and demonstrate dependency injection.

## [26. Environment Variables](26envVariables.go)
Read and print an environment variable.

## [27. Simple Logger]()
Implement a simple logger that writes logs to a file with timestamps.

## [28. RESTful API (CRUD)]()
Create a RESTful API for managing a list of tasks (CRUD operations).

## [29. Unit Testing]()
Write unit tests for a function (e.g., palindrome checker).

## [30. Benchmarking]()
Benchmark a function using Go's testing package.

## [31. Context with Timeout]()
Use `context.WithTimeout` to cancel a long-running operation.

## [32. Middleware for HTTP Server]()
Add a logging middleware to your HTTP server.

## [33. Upload File via HTTP]()
Create an endpoint to upload a file and save it to disk.

## [34. Consume JSON API]()
Consume a JSON API, parse the response, and display selected fields.

## [35. Concurrent Web Scraper]()
Write a concurrent web scraper that fetches titles from a list of URLs.
